Bank Management System

A Python-based Bank Management System built using Object-Oriented Programming, Modules & Packages, Exception Handling, and JSON file storage.

Features

- Create bank accounts
- Deposit money
- Withdraw money
- Check account balance
- View account details
- View transaction history
- Store account data using JSON
- Load saved account data when the application starts
- Handle invalid user input and errors

Technologies Used

- Python
- Object-Oriented Programming
- Modules & Packages
- Exception Handling
- JSON
- File Handling

How to Run

Run the following command from the BankManagement folder:

python main.py

Learning Purpose

This project was developed to practice Python programming concepts and understand how a real-world application can be organized using modules, packages, classes, data persistence, and error handling.
